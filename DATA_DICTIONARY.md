# Data Dictionary

## `data/final/verified_inputs.csv`

| Column | Type | Description |
|---|---|---|
| `company` | string | Company name as reported in its own filing |
| `basis` | string | `consolidated` for all rows — the project standard where both bases are available |
| `fy` | string | `FY25` or `FY26` (year ended 31-Mar) |
| `total_assets` | float, ₹ Crore | Balance sheet total assets |
| `total_equity` | float, ₹ Crore | Total equity attributable + minority interest, as reported |
| `total_liabilities` | float, ₹ Crore | Balance sheet total liabilities |
| `pat` | float, ₹ Crore | Profit after tax, consolidated (FY26 rows only — FY25 PAT wasn't needed by the model and wasn't extracted) |
| `cfo` | float, ₹ Crore | Cash flow from operating activities, consolidated (FY26 rows only) |
| `source_page_note` | string | Exact filing and page(s) this row's figures came from, plus any conversion applied (e.g. PSP's ₹ Lakh → ₹ Crore) |

PSP Projects reports in ₹ Lakh in its source filing; all PSP figures in this
CSV are already converted to ₹ Crore (divided by 100) — see each row's
`source_page_note`.

## `data/final/accrual_screen.csv`

Output of `src/accruals.py::compute_accruals()`. All columns from
`verified_inputs.csv` (FY26 rows only) plus:

| Column | Type | Description |
|---|---|---|
| `avg_total_assets` | float, ₹ Crore | Mean of FY25 and FY26 total assets |
| `total_accruals` | float, ₹ Crore | `pat − cfo` |
| `accrual_ratio` | float | `total_accruals / avg_total_assets` — the core metric. Positive = profit exceeded operating cash generated |
| `cfo_pat_ratio` | float | `cfo / pat` — a second, more intuitive framing of the same relationship |
| `rank_worst_to_best` | int | 1 = highest (worst) accrual ratio, 4 = lowest (best) |

## `data/processed/reconciliation_log.md`

Auto-generated by `src/accruals.py::reconcile_all()`. One line per
company-year confirming `total_assets = total_equity + total_liabilities`
within a ₹1.00 Crore tolerance (`indfin.reconcile.balance_sheet.check_balance_sheet`).
All 8 company-years (4 companies × FY25/FY26) pass with a diff under ₹0.01 Crore.

## `data/raw/source_manifest.md`

One row per source PDF: company, period, exact download URL, retrieval
timestamp, and SHA-256 hash — so a re-download that silently differs from
what was originally reconciled would be caught by hash mismatch, not missed.
